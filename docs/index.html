03 — QUICK START

三步上手

安装插件、打开费用页、勾选免费模型。

下载并安装

标准 DSH bundle，纯 JS 开箱即用；也可从 Release 下载 tarball 本地安装。

dsh plugin --profile web add github:Jensen-Yao/dsh-web-billing
# 或
pnpm add file:./dsh-web-billing-3.0.0.tgz

重启并查看费用

重启 dsh web 后，设置 → 费用 即见汇总；目录启动时后台刷新（可配）。

catalog:
  enabled: true
  ttlMs: 43200000   # 12h
  refreshOnStartup: true

白嫖一键入账

免费模型面板展开供应商 → 勾选模型 → 应用变更 → 确认。历史自动按 0 重估。

GET  /billing/free-models
POST /billing/free-models/apply
     { provider, models[], action }
